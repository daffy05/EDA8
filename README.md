# Exploratory Data Analysis – Student Performance

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Students Performance dataset using Python. It explores student scores in Mathematics, Reading, and Writing to identify patterns, relationships, and differences in academic performance.

## 🛠️ Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📂 Dataset
**Dataset:** Students Performance

The dataset contains the following information:
- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

## 🔍 Data Analysis and Operations

### 1. Data Inspection
- Displayed the first few rows.
- Checked dataset shape and column names.
- Inspected data types and dataset information.
- Checked for missing values.
- Generated descriptive statistics.

### 2. Data Cleaning
- Standardized categorical values.
- Removed leading and trailing spaces.
- Converted categorical columns to string format.
- Checked for outliers using the IQR method.
- Exported the processed dataset as a CSV file.

### 3. Statistical Analysis
- Calculated Mean.
- Calculated Median.
- Calculated Standard Deviation.
- Calculated Quartiles (Q1, Q2, Q3).
- Created Total Marks and Percentage columns.

### 4. Data Visualization
- Grouped bar chart – Average Scores by Parental Education.
- Grouped bar chart – Average Scores by Lunch Type.
- Box plots – Subject Scores by Test Preparation Course.
- Scatter plots – Relationships between subject scores.
- Correlation heatmap – Correlation between Math, Reading, and Writing scores.

## 📊 Key Objectives
- Understand the structure of the dataset.
- Explore student academic performance.
- Compare average scores across different categories.
- Identify relationships between subject scores.
- Examine score distributions and potential outliers.
- Present findings through visualizations.

## 📁 Project Files

- `EDA_TASK_7.ipynb` – Jupyter Notebook containing the analysis.
- `Student_Performance_Cleaned.csv` – Exported processed dataset.

## 🎯 Conclusion
This project demonstrates how Python libraries can be used to inspect, clean, analyze, and visualize student performance data. The analysis helps explore academic score patterns and relationships between different subjects and student-related factors.
